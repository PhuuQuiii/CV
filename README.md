# CV Public Deployment (GitHub Pages)

This repository is ready to publish as a public website.

## Steps to enable GitHub Pages

1. Go to repository **Settings** → **Pages**.
2. In **Build and deployment**, choose **Deploy from a branch**.
3. Select branch `main` and folder `/ (root)`.
4. Click **Save**.

After GitHub finishes building, your public URL will be:

- `https://phuuquiii.github.io/CV/`

## Notes

- `index.html` is added as the homepage to ensure stable browser rendering.
- `index.md` is kept as the source CV content.
